# Atlas docs

Atlas is a multipurpose, hackable, and extensible Windows-first CLI. Its C++ core handles system integration, while Lua lets you add commands, automate workflows, and shape the experience.

- [Commands](commands.md) — everyday commands and examples.
- [Lua](lua.md) — configuration, custom commands, plugins, and the API.
- [Themes](themes.md) — colors, identity, home screen, and art.
- [Build](build.md) — requirements, build, install, and resource paths.
